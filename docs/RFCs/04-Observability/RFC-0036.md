## 1. Scope

This RFC collects the conformance-test obligations for the Observability Architecture. It aggregates tests from RFC-0031 (Event Model), RFC-0032 (Trace Span), RFC-0033 (Replay Format), RFC-0034 (Audit Log), and RFC-0035 (Diagnostic Query), plus cross-observability tests.

---

## 2. Normative Requirements

### 2.1 Core Conformance

`RFC-0036.1`: Every implementation MUST pass the following Observability tests, regardless of profile:

**Event Model:**
- `CTS-OBS-EVT-1` through `CTS-OBS-EVT-6` (RFC-0031)

**Trace Span:**
- `CTS-OBS-SPAN-1` through `CTS-OBS-SPAN-5` (RFC-0032)

**Replay Format:**
- `CTS-OBS-REPLAY-1` through `CTS-OBS-REPLAY-5` (RFC-0033)

**Audit Log:**
- `CTS-OBS-AUDIT-1` through `CTS-OBS-AUDIT-5` (RFC-0034)

**Diagnostic Query:**
- `CTS-OBS-DIAG-1` through `CTS-OBS-DIAG-6` (RFC-0035)

### 2.2 Cross-Observability Tests

`RFC-0036.2`: The following cross-cutting Observability tests are mandatory:

- `CTS-OBS-XS-1`: validates that every event emitted by any RFC has its `correlation_id` populated for all correlated trace spans.
- `CTS-OBS-XS-2`: validates that the audit log and the replay log are consistent: every security-relevant event in the replay log appears in the audit log.
- `CTS-OBS-XS-3`: validates that the diagnostic query interface respects authorization: a query for security events without `QUERY_SECURITY_EVENTS` capability returns empty results, not an error.
- `CTS-OBS-XS-4`: validates that the replay log checksum matches the declared checksum after a complete read.

### 2.3 Profile-Specific Conformance

`RFC-0036.3`: Safety-Critical profile additionally requires:
- `CTS-OBS-AUDIT-4` (auditor signature) MUST pass.
- All security-class events (0x0700) MUST be fully recorded (no sampling).
- `CTS-OBS-REPLAY-5` (checkpoint consistency) MUST pass.

`RFC-0036.4`: Cloud profile additionally requires:
- Audit log retention test (`CTS-OBS-AUDIT-4`) at 1-year minimum declared.
- Diagnostic query streaming mode (`CTS-OBS-DIAG-2` in streaming mode).

### 2.4 Reporting Format

`RFC-0036.5`: Observability conformance declarations MUST publish:
- Per-RFC test results (pass/fail/skipped with justification)
- Sampling policy declarations
- Audit log retention period
- Predefined query definitions
- Query authorization capability declarations

---

## 3. Conformance Tests

This RFC aggregates tests and declares the following cross-cutting tests:

- `CTS-OBS-CONF-1`: validates RFC-0036.1 — all core tests passed.
- `CTS-OBS-CONF-2`: validates RFC-0036.2 — cross-observability tests.
- `CTS-OBS-CONF-3`: validates RFC-0036.3 — Safety-Critical profile tests.
- `CTS-OBS-CONF-4`: validates RFC-0036.4 — Cloud profile tests.
- `CTS-OBS-CONF-5`: validates RFC-0036.5 — reporting format.
