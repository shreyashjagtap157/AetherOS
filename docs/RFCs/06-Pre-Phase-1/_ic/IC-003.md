# IC-003: DMA-Capable Pool Descriptor

Implementation Contract ID: IC-003
Source Requirement: RFC-ALLOC-001.9, RFC-ALLOC-001.16, RFC-ALLOC-001.19, RFC-ALLOC-001.4.2
Owner: Physical Memory Manager (`aether-storage-model`, buddy page allocator)
Realised Invariants: I-1, I-2
Implementation Components: ZONE_DMA and ZONE_DMA32 zone trackers; dma_region_descriptor; buddy allocator zone selection
ABI / Behavioral Contract:
    CAP_DMA_MEMORY token (type 8): target_object = dma_region_descriptor { region_id, base_paddr, size_bytes, dma_width, numa_node, device_id, iommu_domain }.
    DMA capability issued only from ZONE_DMA or ZONE_DMA32; a DMA allocation request from ZONE_NORMAL is rejected (EALLOCDMAZONE) unless the zone constraint is explicitly waived in the conformance declaration.
    The capability-mediator programs the IOMMU translation entry on presentation of a valid CAP_DMA_MEMORY; the driver never holds CAP_IOMMU_CONFIG.
CTS Test: CTX-ALLOC-008
Formal Property: none
Observation Record: none
Status: DRAFT
