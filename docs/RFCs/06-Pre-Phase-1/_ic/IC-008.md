# IC-008: Position-Independent Code ABI Slice

Implementation Contract ID: IC-008
Source Requirement: RFC-COMPILER-001.31, RFC-COMPILER-001.32, RFC-COMPILER-001.33, RFC-COMPILER-001.34, RFC-COMPILER-001.35
Owner: Toolchain / linker (`reference/` toolchain configuration); component loader
Realised Invariants: I-9
Implementation Components: GOT region definition; relocation table format (REL_CAPABILITY, REL_CAP_GOT, REL_DATA, REL_FUNC); load-time relocation engine; ASLR base-address selection
ABI / Behavioral Contract:
    Components MUST be compiled as position-independent code (PIC); load addresses determined at load time by the Composition Root, not at compile time.
    GOT-based capability-relative relocations: each capability reference resolved through a GOT entry populated at load time containing the capability token's in-memory address.
    Relocation types: REL_CAPABILITY (provider-width live capability handle slot), REL_CAP_GOT (GOT entry for capability reference), REL_DATA (data pointer, address-relative), REL_FUNC (function pointer, address-relative).
    Component address space layout (low → high): guard region, stack region, TLS region, code region (PIC, RIGHT_EXECUTE), data region (READ+WRITE), GOT region (READ+WRITE), heap region, guard region.
    ASLR optional per profile; Security-Critical profile REQUIRES ASLR.
