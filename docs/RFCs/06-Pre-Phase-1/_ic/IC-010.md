# IC-010: Driver Manifest Schema

Implementation Contract ID: IC-010
Source Requirement: RFC-DRIVER-001.12, RFC-DRIVER-001.14, RFC-DRIVER-001.32
Owner: Component loader; driver manifest validator
Realised Invariants: I-2, I-3, I-11
Implementation Components: driver_manifest struct; capability declaration list; dependency declaration list; manifest parser and validator
ABI / Behavioral Contract:
    driver_manifest extends RFC-0002 component_manifest with: device_class (u16), device_vendor (u16), device_product (u16), capability_count (u8), dependency_count (u8), flags (u16), followed by capability_count × capability declarations and dependency_count × dependency declarations.
    Flags: 0x01 DRV_HOTPLUG, 0x02 DRV_SUSPEND, 0x04 DRV_REPLACABLE, 0x08 DRV_CRITICAL.
    Driver Capability Broker MUST verify every capability granted to a driver is declared in the manifest; granting an undeclared capability is non-conformant (RFC-DRIVER-001.18, I-2).
CTS Test: none dedicated (covered by CTX-DRIVER-003)
Formal Property: none
Observation Record: none
Status: DRAFT
