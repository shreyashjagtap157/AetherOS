# IC-012: DMA Capability and IOMMU Program Request

Implementation Contract ID: IC-012
Source Requirement: RFC-DRIVER-001.15, RFC-DRIVER-001.25, RFC-ALLOC-001.17, RFC-ALLOC-001.18
Owner: Driver Capability Broker; capability-mediator; HAL-BOOT
Realised Invariants: I-1, I-2
Implementation Components: CAP_DMA_MEMORY token (type 8); IOMMU program-request path; DMA window descriptor
ABI / Behavioral Contract:
    Driver receives CAP_DEVICE_CONTROL and CAP_DMA_MEMORY for its device; MAY also receive CAP_MMIO_REGION for MMIO register space.
    Driver does NOT receive CAP_IOMMU_CONFIG (type 9) — reserved for capability-mediator only.
    When driver presents valid CAP_DMA_MEMORY to mediator, mediator programs IOMMU translation entries mapping device DMA window to backing pages as an internal technical effect.
    Revocation of CAP_DMA_MEMORY (RFC-0039) causes mediator to invalidate IOMMU translation entry within declared revocation latency bound; device faults on subsequent DMA access.
CTS Test: CTX-DRIVER-001, CTX-DRIVER-002
Formal Property: PF-DRIVER-001 — DMA access requires valid CAP_DMA_MEMORY token; IOMMU invalidation on revocation (I-1, I-2)
Observation Record: none
Status: DRAFT
