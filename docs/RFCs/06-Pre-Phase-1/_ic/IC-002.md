# IC-002: Stack and Heap Allocation Capability Boundaries

Implementation Contract ID: IC-002
Source Requirement: RFC-ALLOC-001.23, RFC-ALLOC-001.25, RFC-ALLOC-001.26, RFC-ALLOC-001.28
Owner: Capability Authority Manager; component runtime (`aether-runtime-model`)
Realised Invariants: I-1, I-2, I-3
Implementation Components: stack descriptor; heap descriptor; heap derivation path; domain-bound capability tags
ABI / Behavioral Contract:
    Stack capability: CAP_MEMORY over a contiguous stack region (READ + WRITE, fixed size), CAPF_BOUND; guard pages excluded from target_object size per RFC-ALLOC-001.24 / question 4.
    Heap capability: CAP_MEMORY granting RIGHT_DERIVE + RIGHT_WRITE on a managed heap region; derivable into narrower heap capabilities whose sub-allocations cannot exceed the derived region's bounds (RFC-ALLOC-001.26).
    Stack and heap capabilities domain-bound — invalid outside the creating component's domain (RFC-ALLOC-001.28).
CTS Test: CTX-ALLOC-002
Formal Property: PF-ALLOC-002 — derived allocation rights are a subset of parent rights (I-3); PF-ALLOC-003 — stack/heap capabilities invalid outside creating domain (I-2)
Observation Record: none
Status: DRAFT
