# IC-011: Device-Control Capability

Implementation Contract ID: IC-011
Source Requirement: RFC-DRIVER-001.14, RFC-DRIVER-001.15, RFC-0037 type 12
Owner: Driver Capability Broker (`aether-cap-model`)
Realised Invariants: I-1, I-2, I-3
Implementation Components: device-control capability type (type 12); device registry lookup; capability grant path
ABI / Behavioral Contract:
    CAP_DEVICE_CONTROL token (type 12): target_object = device_id (object_id per RFC-0015 referencing the device registered by HAL at boot).
    Grants device register operations (read/write/status) for the device the driver services.
    Granted only for the device the driver services; bound to driver domain; not transferable unless DRV_HOTPLUG declared and transfer is part of device handoff.
CTS Test: none dedicated (covered by CTX-DRIVER-003)
Formal Property: none
Observation Record: none
Status: DRAFT
